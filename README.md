# Student Record Management System — Group 3

A centralized system designed to streamline the creation, storage, retrieval, and updating of student information, academic records, and enrollment details.

## Overview
This project replaces manual record-keeping with a structured, easy-to-use platform built by **Group 3**. It allows administrators and educators to securely manage student profiles, track academic performance, and maintain accurate records in one place.

## Key Features
- **Student Profile Management:** Add, view, update, and delete student personal and contact details.
- **Academic & Grade Tracking:** Record and organize courses, subjects, and student grades.
- **Search & Filter:** Quickly locate student records by ID, name, or course/section.
- **Data Validation & Integrity:** Ensures accurate and consistent student entries.
